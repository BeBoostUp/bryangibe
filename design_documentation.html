1. Application Overview

The Google Ads Campaign Management Dashboard is an internal tool built by Bryan Gibe, a freelance digital marketing consultant, to manage and monitor Google Ads campaign performance across all client accounts managed under an MCC (My Client Center) account.

The tool provides a unified control center for all campaigns in a single dashboard, enabling faster decision-making, performance diagnostics, and efficient campaign management across multiple client accounts.

2. Purpose and Business Need

  • Centralized Control: Manage and monitor all client campaigns from the MCC in one place
  • Real-time Performance Tracking: Monitor key metrics (spend, clicks, impressions, conversions, CTR, CPC, ROAS) in real-time
  • Campaign Diagnostics: Automated scoring system to identify campaigns that should be scaled, maintained, or paused
  • Faster Decision Making: Quickly identify underperforming campaigns and take action
  • Operational Efficiency: Reduce time spent switching between accounts in the Google Ads UI
  • Custom Date Ranges: Analyze performance across different time periods with period-over-period comparison

4.2 Data Flow

  1. User logs into the dashboard with a password
  2. Dashboard loads the list of accounts from the MCC
  3. User selects an account (or "All Accounts" for MCC-wide view) and date range
  4. Backend sends GAQL queries to Google Ads API (SearchStream)
  5. API returns campaign performance data and daily trends
  6. Frontend displays KPI cards, trend charts, type distribution, and campaign diagnostics
  7. Scoring algorithm classifies campaigns as Scale / Maintain / Review

5. Key Features

5.1 Dashboard Views

  • All Accounts (MCC) View: Aggregated metrics across all client accounts with account breakdown table
  • Single Account View: Detailed campaign-level data for individual accounts
  • Period Comparison: Compare current vs previous period with percentage change indicators

5.2 Campaign Diagnostics

Automated scoring system that evaluates each campaign based on:

  • ROAS (Return on Ad Spend)
  • CTR relative to account average
  • CPC relative to account average
  • Conversion rate and cost per conversion
  • Search impression share and budget utilization
  • Click-to-conversion efficiency

Campaigns are classified into three categories:

  • Scale (Green): High-performing campaigns with room to grow
  • Maintain (Yellow): Acceptable performance, monitor closely
  • Review/Stop (Red): Underperforming campaigns requiring attention

5.3 Visualizations

  • 10 KPI summary cards with trend indicators
  • Daily trend line chart (spend and conversions)
  • Campaign type distribution doughnut chart
  • Sortable campaign table with all metrics
  • CSV export functionality

6. Security and Access Control

  • Authentication: Password-based login with SHA-256 hashing
  • Access: Internal use only (single user - consultant)
  • Data storage: No campaign data is stored; all data is fetched in real-time from the API
  • Credentials: OAuth2 tokens and API keys stored as environment variables (not in source code)
  • HTTPS: All communication over HTTPS (enforced by Vercel)
  • No data sharing: Data is not shared with third parties

7. OAuth2 Implementation

  • OAuth2 flow: Authorization Code flow with offline access
  • Scopes requested: https://www.googleapis.com/auth/adwords
  • Token storage: Refresh token stored as secure environment variable in Vercel
  • Token refresh: Access token refreshed automatically when expired

8. Compliance

  • The application complies with the Google Ads API Terms of Service
  • The application complies with the Google API Services User Data Policy
  • No Google Ads data is sold, shared, or transferred to third parties
  • The application is used exclusively for internal business operations
