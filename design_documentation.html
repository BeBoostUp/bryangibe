1. Application Overview

The Google Ads Performance Dashboard is an internal reporting tool built by BeBoostUp, a digital marketing agency, to monitor and analyze Google Ads campaign performance across all client accounts managed under our MCC (My Client Center) account.

The tool provides a unified view of all campaigns in a single dashboard, replacing the need to manually check each account individually in the Google Ads interface or use third-party reporting tools.

2. Purpose and Business Need

  • Centralized Monitoring: View all client campaigns from the MCC in one place
  • Real-time Performance Tracking: Monitor key metrics (spend, clicks, impressions, conversions, CTR, CPC) in real-time
  • Faster Decision Making: Quickly identify underperforming campaigns and take action
  • Internal Efficiency: Reduce time spent switching between accounts in the Google Ads UI
  • Custom Date Ranges: Analyze performance across different time periods

  • Estimated daily requests: Less than 1,000 requests/day
  • Data usage: Reporting and visualization only
  • No automated bidding or campaign management

4.2 Data Flow

  1. User logs into the dashboard with a password
  2. Dashboard loads the list of accounts from the MCC
  3. User selects an account and date range
  4. Backend sends GAQL query to Google Ads API (SearchStream)
  5. API returns campaign performance data
  6. Frontend displays data in KPI cards and sortable table

5. User Interface

5.1 Login Screen

Password-protected access. Only authorized BeBoostUp team members can log in.

5.2 Dashboard Screen

The main dashboard includes:

  • Account Selector: Dropdown to choose the Google Ads account to view
  • Date Range Controls: Date pickers and presets (Today, Yesterday, 7 days, 30 days, This Month, Last Month)
  • KPI Summary Cards: Total Spend, Impressions, Clicks, CTR, Avg CPC, Conversions, Cost/Conversion, Conversion Rate
  • Campaign Table: Sortable table showing all campaigns with status, type, and all performance metrics
  • Search Filter: Text search to filter campaigns by name

6. Security and Access Control

  • Authentication: Password-based login with SHA-256 hashing
  • Access: Internal users only (BeBoostUp employees)
  • Data storage: No campaign data is stored; all data is fetched in real-time from the API
  • Credentials: OAuth2 tokens and API keys stored as environment variables (not in source code)
  • HTTPS: All communication over HTTPS (enforced by Vercel)
  • No data sharing: Data is not shared with third parties

7. OAuth2 Implementation

  • OAuth2 flow: Authorization Code flow with offline access
  • Scopes requested: https://www.googleapis.com/auth/adwords
  • Token storage: Refresh token stored as secure environment variable in Vercel
  • Token refresh: Access token refreshed automatically when expired

8. Compliance

  • The application complies with the Google Ads API Terms of Service
  • The application complies with the Google API Services User Data Policy
  • No Google Ads data is sold, shared, or transferred to third parties
  • The application is used exclusively for internal business reporting
  • All API usage is read-only; no automated campaign modifications are performed
